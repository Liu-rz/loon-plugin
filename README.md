## 安装与使用

1. 从上面的目录复制需要的插件订阅地址。
2. 在 Loon「插件」中添加地址，下载并启用插件。
3. 开启 Loon 连接；含分流规则的插件使用规则分流模式。涉及重写时开启「重写／复写」；涉及 HTTPS 重写时，还需开启 MITM，安装并完全信任 Loon CA 证书。
4. 从后台退出目标 App，再重新打开测试。配置缓存可能需要等 App 重新获取后才更新。

**订阅必须使用 `raw.githubusercontent.com` 上的具体 `.plugin` 文件地址。** `https://github.com/Liu-rz/loon-plugin.git` 是 Git 仓库地址，不能作为插件订阅地址；GitHub 文件预览页也不是订阅地址。

安装证书后，在 iPhone「设置 → 通用 → 关于本机 → 证书信任设置」中完全信任对应证书。各插件的最低版本要求和额外条件见对应说明。

## 仓库结构

- 根目录中的 `*.plugin`：各 App 的独立插件，直接供 Loon 订阅。
- `docs/`：各插件的接口依据、适用范围、使用条件、验证结果和已知问题。
- `README.md`：通用安装步骤、插件目录及更新记录。
- `AGENTS.md`：后续插件开发与文档同步约定。

## 维护约定

- 每新增一个 App 插件，同步添加目录项、订阅地址和对应说明文件。
- 每次修改插件，同步更新处理范围、日期、验证状态及本页更新记录；未经真机验证不得标记为已验证。
- 保留已有插件订阅路径，避免更新其他 App 时使旧订阅失效。
- 优先采用抓包证据支持的接口级规则，说明可能影响共享接口的其他 App。
- 不提交原始 HAR、Cookie、令牌、设备标识、签名、证书私钥或其他敏感数据。文档只记录脱敏后的接口信息。

## 问题反馈

反馈时请说明 App 名称与版本、Loon 版本、广告出现位置及复现步骤，并确认插件、重写、MITM 和证书信任状态。需要补充抓包时，请先脱敏。
